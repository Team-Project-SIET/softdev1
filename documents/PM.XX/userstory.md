#  Agile Scrum Project: Laundry Shop Management System
**Sprint Goal:** พัฒนาระบบพื้นฐานให้ลูกค้าจองคิวได้ และแอดมินเห็นออเดอร์ 

## Product Backlog & Prioritization

| ID | User Story (ความต้องการ) | Priority (ความสำคัญ)  | ผู้รับผิดชอบเขียน |
|:---:|:---|:---:|:---:|
| **US-01** |  **user** ต้องการ **สมัครสมาชิก/เข้าสู่ระบบ** เพื่อเริ่มใช้งานและระบุตัวตน | **High** |  อรัญชัย คำเพ็ญ |
| **US-02** | **user** ต้องการ **จองคิวซักรีดและระบุเวลารับ** เพื่อให้รถมารับผ้า | **High** |  อรัญชัย คำเพ็ญ |
| **US-03** | ในฐานะ **Admin** ต้องการ **ดูรายการออเดอร์ที่เข้ามาใหม่** เพื่อจัดเตรียมรถไปรับ | **High** |  อรัญชัย คำเพ็ญ |
| **US-04** | **user** ต้องการ **ดูสถานะผ้า (ซัก/รีด/เสร็จ)** เพื่อติดตามงาน | Medium | อรัญชัย คำเพ็ญ |
| **US-05** | **Admin** ต้องการ **เปลี่ยนสถานะออเดอร์** เพื่อแจ้งลูกค้าว่าถึงขั้นตอนไหน | Medium | อรัญชัย คำเพ็ญ |
| **US-06** | **Admin** ต้องการ **Dashboard สรุปยอดขาย** เพื่อดูรายได้รายวัน | **High** | อรัญชัย คำเพ็ญ |

## Sprint Planning (Task Breakdown)

### Item: US-01 ระบบสมัครสมาชิก/เข้าสู่ระบบ (Login)
| Task ID | Task Description | Assignee |
|:---:|:---|:---|
| T-01-A | ออกแบบหน้าจอ Login/Register (UI Design) | สรวิชญ์ สมตน |
| T-01-B | สร้าง Database Table `Users` (ID, User, Password, Tel, Address) | อรัญชัย คำเพ็ญ |
| T-01-C | เขียนโค้ดหน้า Form สมัครสมาชิก (Frontend) | อนาวิล บุญช่วย |
| T-01-D | เขียน API สำหรับตรวจสอบ Login (Backend) | วรปรัชญ์ บุญมี |

### Item: US-02 ระบบจองคิวซักรีด (Booking)
| Task ID | Task Description | Assignee |
|:---:|:---|:---|
| T-02-A | ออกแบบหน้าฟอร์มจองคิว (UI Design) | สรวิชญ์ สมตน |
| T-02-B | สร้าง Database Table `Orders` และ `Order_Details` | อรัญชัย คำเพ็ญ |

| T-02-D | เขียน Logic บันทึกข้อมูลการจองลงฐานข้อมูล (Backend) | วรปรัชญ์ บุญมี |
