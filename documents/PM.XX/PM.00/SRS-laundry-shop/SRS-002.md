# 1. บทนำ (Introduction)

## 1.1 วัตถุประสงค์

พัฒนาระบบบริหารจัดการธุรกิจซักรีดแบบครบวงจร รองรับลูกค้าทั่วไป (B2C) และลูกค้าองค์กร (B2B)  
โดยเน้นประสิทธิภาพด้านโลจิสติกส์ การจัดการคำสั่งซื้อ และ **Financial Dashboard** ที่ดึงข้อมูลธุรกรรมจากธนาคารผ่าน **SCB Developer API (Sandbox)** เพื่อนำมาวิเคราะห์รายรับ รายจ่าย และกำไรของธุรกิจ

---

## 1.2 ขอบเขต (Scope)

1. **Operation:** ระบบจัดการ Order และ Tracking สถานะงานซักรีด  
2. **Customer Service:**  
   - B2C ผ่าน **LINE OA และ Web Portal**  
   - B2B ผ่านระบบสัญญา  
3. **Logistics:** ระบบมอบหมายงานให้ Driver และติดตามสถานะงานรับ–ส่ง  
4. **Financial:** เชื่อมต่อ SCB API เพื่อดึงข้อมูลธุรกรรมและสร้าง Dashboard การเงิน

---

# 2. ผู้ใช้งานระบบ (User Roles)

## 2.1 ผู้ดูแลระบบ / พนักงาน (Admin / Staff)

ผู้ใช้งานหลักของระบบ

หน้าที่

- คีย์ Order
- จัดการ Workflow งานซัก
- มอบหมายงานให้ Driver
- ตรวจสอบข้อมูลการเงิน

---

## 2.2 พนักงานขับรถ (Driver)

หน้าที่

- ดูรายการงานผ่านมือถือ
- กดอัปเดตสถานะงาน
- รับและส่งผ้าให้ลูกค้า

---

## 2.3 ลูกค้าทั่วไป (General Customer - B2C)

ลูกค้าทั่วไปสามารถใช้งานระบบผ่าน

- **LINE OA**
- **Customer Web Portal**

ความสามารถ

- ตรวจสอบสถานะงานซักรีด
- ดูประวัติการใช้บริการ
- ดูรายละเอียด Order

---

## 2.4 ลูกค้าองค์กร (Corporate Client - B2B)

- ติดต่อ Admin ผ่านโทรศัพท์หรือ LINE
- มีข้อมูลสัญญาอยู่ในระบบ

---

## 2.5 ผู้บริหาร (Executive)

สามารถดู

- Dashboard การเงิน
- รายงานกำไรขาดทุน
- สถิติธุรกิจ

---

# 5. ความต้องการที่ไม่ใช่ฟังก์ชัน (Non-Functional Requirements)

1. **Security**  
ข้อมูลการเงินต้องถูกเข้ารหัส และจำกัดการเข้าถึงตาม Role

2. **Accuracy**  
ข้อมูลธุรกรรมต้องตรงกับ SCB API

3. **Availability**  
ระบบต้องพร้อมใช้งานตลอดเวลา

4. **Usability**  
หน้าจอพนักงานต้องใช้งานง่ายและลดจำนวนขั้นตอน
