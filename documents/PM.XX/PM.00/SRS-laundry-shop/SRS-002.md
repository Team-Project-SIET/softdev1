## 1. บทนำ (Introduction)
### 1.1 วัตถุประสงค์
เอกสารนี้อธิบายข้อกำหนดความต้องการซอฟต์แวร์สำหรับ **ระบบบริหารจัดการร้านรับซักรีดเสื้อผ้า** โดยมีวัตถุประสงค์เพื่อพัฒนาระบบ Web Application ที่มีความสามารถดังนี้:
- บริหารจัดการร้านซักรีดแบบครบวงจร (หน้าร้านและออนไลน์)
- นำเทคโนโลยี **RFID** มาช่วยในการติดตามสถานะงานอัตโนมัติ (Automation)
- เชื่อมต่อกับ **LINE Official Account (LINE OA)** เพื่อแจ้งเตือนลูกค้า
- รองรับการใช้งานผ่านอุปกรณ์ **POS Terminal** และ Tablet
- สร้างรายงานและ Dashboard เพื่อวิเคราะห์ประสิทธิภาพการทำงาน

### 1.2 ขอบเขต
ระบบจะครอบคลุมการทำงานหลักดังนี้:
- ระบบสมาชิกและ CRM
- การรับเสื้อผ้าและจับคู่กับ RFID Tag
- Smart Tracking System: การติดตามสถานะด้วย RFID ตามโซนพื้นที่
- การแจ้งเตือนลูกค้าผ่าน LINE OA
- การจัดการกระบวนการซัก/รีด/แพ็ค/จัดเก็บ
- การชำระเงิน (รองรับ POS และ Online)
- การจัดการสต็อกและอุปกรณ์
- การออกรายงานและ Dashboard วิเคราะห์คอขวด (Bottle Neck)

## 2. ความต้องการด้านฟังก์ชันการทำงาน (Functional Requirements)

### 2.1 การจัดการลูกค้าและสมาชิก
1. **ข้อมูลลูกค้า:** จัดการข้อมูลส่วนตัว, ที่อยู่, LINE ID, ประวัติการใช้บริการ
2. **ระดับสมาชิก (Membership):**
   - แบ่งเป็นลูกค้าทั่วไป และ **VIP**
   - ระบบสะสมแต้มและแลกส่วนลด
   - สิทธิพิเศษสำหรับ VIP (เช่น บริการด่วนฟรี, ส่วนลดค่าซัก)

### 2.2 การรับเสื้อผ้า (Reception)
1. **การสร้างใบรับงาน (Order):**
   - บันทึกข้อมูลลูกค้าและรายการผ้า (ประเภท, จำนวน, จุดตำหนิ, รูปถ่าย)
   - เลือกบริการ (ซักอบรีด, ซักแห้ง, สปา, ซ่อมแซม)
2. **การจับคู่ RFID (Tagging):**
   - ผูกข้อมูล **Order ID** เข้ากับ **รหัส RFID ของตะกร้าผ้า**
   - หนึ่งคำสั่งงานต่อหนึ่งตะกร้า (หรือมากกว่า) เพื่อใช้ในการติดตาม
3. **การประมาณราคา:** คำนวณราคาเบื้องต้นและวันนัดรับ

### 2.3 ระบบติดตามงานอัจฉริยะ (Smart Tracking & Process)
*ระบบจะอัปเดตสถานะอัตโนมัติเมื่อตะกร้าผ้าถูกเคลื่อนย้ายผ่านเครื่องอ่าน RFID ในแต่ละโซน*

1. **โซนซัก (Washing Zone):**
   - เมื่อตะกร้าเข้าพื้นที่ -> เปลี่ยนสถานะเป็น **"กำลังซัก"**
   - บันทึกเวลาเริ่มซัก

2. **โซนรีด (Ironing Zone):**
   - เมื่อตะกร้าเข้าพื้นที่ -> เปลี่ยนสถานะเป็น **"กำลังรีด"**
   - บันทึกเวลาเริ่มรีด

3. **โซนแพ็ค (Packing Zone):**
   - เมื่อตะกร้าเข้าพื้นที่ -> เปลี่ยนสถานะเป็น **"กำลังแพ็ค"**
   - พนักงานทำการตรวจสอบความเรียบร้อยครั้งสุดท้าย

4. **โซนจัดเก็บ (Storage Zone):**
   - เมื่อนำตะกร้า/ห่อผ้าไปวางที่ชั้น -> เปลี่ยนสถานะเป็น **"รอส่งมอบ"**
   - ระบบระบุตำแหน่งชั้นวาง (Location) อัตโนมัติ เพื่อความสะดวกในการหยิบ

5. **Manual Override:**
   - พนักงานสามารถกดเปลี่ยนสถานะด้วยมือผ่านหน้าจอสัมผัสได้ กรณีระบบ RFID ขัดข้อง

### 2.4 การแจ้งเตือนและติดตามสถานะ (Notification)
1. **LINE Official Account (LINE OA):**
   - **Push Notification:** แจ้งเตือนลูกค้าอัตโนมัติเมื่อสถานะเปลี่ยน (เช่น ซักเสร็จแล้ว, พร้อมรับ, กำลังไปส่ง)
   - **Menu:** ลูกค้ากดเมนูเพื่อเช็คสถานะและประวัติได้ด้วยตนเอง
2. **Web Portal:** หน้าเว็บสำหรับลูกค้าเพื่อดูรายละเอียดคำสั่งซื้อ

### 2.5 การคืนเสื้อผ้าและการชำระเงิน
1. **การส่งมอบ (Delivery/Pickup):**
   - ค้นหาผ้าจากตำแหน่งชั้นวางที่ระบบระบุ
   - ตรวจสอบรายการผ้าก่อนส่งมอบ
2. **การชำระเงิน (POS System):**
   - หน้าจอออกแบบสำหรับ POS Terminal (Touch Screen)
   - รองรับการชำระแบบ: เงินสด, โอนเงิน (แนบสลิป), QR Payment
   - ออกใบเสร็จรับเงิน/ใบกำกับภาษี

### 2.6 การจัดการบริการพิเศษ
- **บริการรับ-ส่ง (Delivery Service):** คำนวณค่าส่งตามระยะทาง/โซน
- **ลูกค้าองค์กร:** รองรับระบบวางบิล (Credit Term) รายเดือน

### 2.7 การจัดการสต็อกและอุปกรณ์
- ตัดสต็อกน้ำยาอัตโนมัติ (ตามสูตรการซักที่ใช้)
- แจ้งเตือนเมื่อสินค้าใกล้หมด (Re-order Point)
- บันทึกประวัติการซ่อมบำรุงเครื่องจักร

### 2.8 ระบบ Dashboard และรายงาน
1. **Operational Dashboard:**
   - แสดงสถานะงานแบบ Real-time (งานกี่ชิ้นอยู่ในโซนซัก/รีด/แพ็ค)
   - **Heatmap:** แสดงจุดที่งานกระจุกตัว (Bottle Neck Analysis) เพื่อแก้ปัญหาคอขวด
2. **Executive Dashboard:**
   - ยอดขายรายวัน/เดือน
   - ประสิทธิภาพพนักงาน และเวลาเฉลี่ยในการทำงานแต่ละขั้นตอน
3. **รายงาน:** รายงานบัญชี, ภาษี, สต็อก, ประวัติลูกค้า

## 3. ความต้องการที่ไม่ใช่ฟังก์ชันการทำงาน (Non-Functional Requirements)

### 3.1 ฮาร์ดแวร์และอุปกรณ์ (Hardware Integration)
1. รองรับการเชื่อมต่อกับ **RFID Reader**
2. รองรับการใช้งานบนเครื่อง **POS Terminal** (หน้าจอสัมผัสแนวนอน)
3. รองรับเครื่องยิง Barcode/QR Code (สำหรับกรณีสำรอง)

### 3.2 ความสามารถในการใช้งาน (Usability)
1. **Responsive Web Design:** แสดงผลได้ดีทั้งบน PC, Tablet และ POS Screen
2. **User Friendly:** ปุ่มกดขนาดใหญ่ ใช้งานง่ายสำหรับหน้าจอสัมผัส

### 3.3 ประสิทธิภาพ (Performance)
1. การอ่านค่า RFID และอัปเดตสถานะต้องทำได้ภายใน 1-2 วินาที
2. รองรับผู้ใช้งานพร้อมกันไม่ต่ำกว่า 100 User

### 3.4 ความปลอดภัย (Security)
1. การเข้ารหัสข้อมูลลูกค้าตามมาตรฐาน PDPA
2. ระบบ Authentication ยืนยันตัวตนพนักงานและลูกค้า
3. Session Timeout เมื่อไม่มีการใช้งาน 140 นาที

## 4. ข้อจำกัดของระบบ (System Constraints)
1. ระบบต้องเชื่อมต่ออินเทอร์เน็ตตลอดเวลาเพื่อซิงค์ข้อมูล Cloud
2. การทำงานอัตโนมัติขึ้นอยู่กับความเสถียรของอุปกรณ์ RFID Hardware
3. เก็บข้อมูลย้อนหลังเป็นเวลา 5 ปี
