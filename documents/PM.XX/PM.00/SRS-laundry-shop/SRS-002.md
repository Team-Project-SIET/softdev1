## 1. บทนำ (Introduction)
### 1.1 วัตถุประสงค์
พัฒนาระบบบริหารจัดการธุรกิจซักรีดแบบครบวงจร ที่รองรับทั้งลูกค้าทั่วไป (B2C) และลูกค้าองค์กร (B2B) โดยเน้นประสิทธิภาพด้านโลจิสติกส์, การจัดการสัญญาจ้าง, และฟีเจอร์เด่นคือ **ระบบอัตโนมัติทางบัญชี (Financial Automation)** ที่ดึงข้อมูลจาก Statement ธนาคารมากระทบยอดและวิเคราะห์ผลกำไร/ขาดทุนให้ผู้บริหารทันที

### 1.2 ขอบเขต (Scope)
1.  **Operation:** ระบบจัดการ Order, **Tracking (Digital Status Update)**, และการขนส่ง (Driver)
2.  **Customer Service:** รองรับ B2C ผ่าน LINE OA และ B2B ผ่านระบบสัญญา (Contract)
3.  **Financial:** เชื่อมต่อ n8n เพื่อประมวลผล Bank Statement และออกรายงานผู้บริหาร

## 2. ผู้ใช้งานระบบ (User Roles)
1.  **ผู้ดูแลระบบ/พนักงาน (Admin/Staff):**
    - ผู้ใช้งานหลัก รับผิดชอบการคีย์ออเดอร์, จัดการคิวซักผ่านหน้าจอ Dashboard, และตรวจสอบยอดเงิน
2.  **พนักงานขับรถ (Driver):**
    - รับผิดชอบการรับ-ส่งผ้า, เช็คอินสถานที่, และกดอัปเดตสถานะงานขนส่งผ่านมือถือ
3.  **ลูกค้าทั่วไป (General Customer - B2C):**
    - ใช้งานผ่าน LINE OA เพื่อดูสถานะและประวัติ
4.  **ลูกค้าองค์กร (Corporate Client - B2B):**
    - *ไม่มีการใช้งานระบบโดยตรง* (เน้นโทร/ไลน์สั่ง Admin) แต่มีข้อมูลสัญญาในระบบ
5.  **ผู้บริหาร (Executive):**
    - ดู Dashboard ภาพรวม, กราฟการเงิน, และรายงาน P/L

## 5. ความต้องการที่ไม่ใช่ฟังก์ชัน (Non-Functional Requirements)
1.  **Security:** ข้อมูลการเงินต้องถูกเข้ารหัส และเข้าถึงได้เฉพาะ Role ที่กำหนด (Executive/Accountant)
2.  **Accuracy:** การแปลงค่าเงินจากไฟล์ Statement ต้องมีความแม่นยำทางทศนิยม 100%
3.  **Availability:** ระบบต้องพร้อมใช้งาน 24/7 (โดยเฉพาะส่วนรับค่าจาก Driver และ LINE OA)
4.  **Usability:** หน้าจอสำหรับพนักงาน (Admin/Driver) ต้องใช้งานง่าย ลดจำนวนการคลิกให้เหลือเท่าที่จำเป็น

## 6. สถาปัตยกรรมระบบ (System Stack)
-   **Frontend:** Next.js 16, Tailwind CSS
    -   *Library:* `@elysiajs/eden` (สำหรับเชื่อมต่อ Type กับ Backend อัตโนมัติ), `@hello-pangea/dnd` (สำหรับ Kanban Board)
-   **Backend (API Server):** **ElysiaJS** (Running on Bun Runtime)
    -   ใช้ **Eden Treaty** เพื่อแชร์ Type ข้อมูลระหว่าง Frontend-Backend และ **Swagger** สำหรับสร้างเอกสาร API อัตโนมัติ
-   **Database:** PostgreSQL (Managed by **Drizzle ORM**)
-   **Automation:** n8n
-   **Deployment:** DigitalOcean
